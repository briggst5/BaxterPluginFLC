# GitHub Copilot Integration

Prefer installing **baxter-flc-platform-sw** from the Copilot agent-plugin marketplace. Shared checklists and review skills ship with the plugin.

## Optional project instructions

You may add `.github/copilot-instructions.md` for **project-specific** standards that extend (not replace) the shared foundation. Point reviewers at plugin skills (`code-review`, `pr-review`) rather than vendoring checklist copies into the app repo.
