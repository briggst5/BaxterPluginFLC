# Cursor IDE Integration

Prefer installing **baxter-flc-platform-sw** from the team marketplace. Skills, rules, and checklists load from the plugin — no per-project copy required.

## Verify

In Cursor chat:

- *"Code review this file using org checklists"*
- *"PR review for my open ADO PR"* (requires Azure CLI + devops extension)

## Optional project rules

You may add project-specific `.cursor/rules/*.mdc` that **extend** (not fork) the plugin checklists. Do not copy checklist files into app repos.
